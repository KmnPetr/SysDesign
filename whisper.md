## 1) Функциональные требования

Добавить к проекту <https://mandarin-video.com/> возможность просмотра видео с <https://www.youtube.com/> и <https://www.douyin.com> с транскрибацией аудио.

По результатам транскрибации отдавать пользователю оригинальный текст + перевод с китайского и английского.

Добавить систему монетизации на основе подсчета токен/время аудио роликов.

## 2) Нефункциональные требования

- Ограничения по времени: лимиты на обработку очень длинных роликов.
- Решить где отделять аудио от видео на стороне клиента или сервера. (особенно если это ютуб с впн-ом)
- Возможность транскрибации видео с ютуба с обходом блокировок. (наверное если клиент смог пройти на ютуб, то пусть сам и отдает аудио файл нам)
- Обработка целого ролика! (для простоты сначала пробуем транскрибировать весь ролик за раз без дробления на части)
- Контроль формата аудио. (whisper принимает определенный формат audio)
- Производитьельность: время транскрибации не должно превышать время ролика.
- Масштабируемость: gpu сервера должны быть горизонтально масштабируемы с ростом количества пользователей.
- Контроль потраченных токенов на транскрибацию.
- использование переводчика для получившегося текста (наверное NLLB-200 distilled 600M не силно тяжел и может переводить en <-> ru <-> zh, также нужен GPU)

## 3) домены

### POST /api/transcribation

Основной пользовательский API для транскрибации видео по ссылке. Клиент отправляет URL ролика, сервер сам скачивает видео или аудио, извлекает аудиодорожку, приводит ее к формату Whisper, выполняет транскрибацию, переводит текст и возвращает результат.

Request:

```json
{
    "url": "https://www.youtube.com/watch?v=..."
}
```

Response:

```json
{
    "originalText": "...",
    "originalLanguage": "zh",
    "translatedText": "...",
    "audioDurationSeconds": 1234,
    "tokenUsage": {
        "transcription": 1000,
        "translation": 2000
    }
}
```

Ошибки:

- 400: некорректный URL или неподдерживаемый источник;
- 402: недостаточно баланса или превышен лимит пользователя;
- 413: ролик слишком длинный или аудио превышает лимит размера;
- 422: не удалось извлечь аудио или формат не поддерживается;
- 500: ошибка транскрибации, перевода или внутренней обработки.
